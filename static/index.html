SMALL MODEL. BIG MEMORIES.

Your kitchen. Your AI.

Sunday Table uses Ollama and the open-weight Qwen 2.5 model to turn family notes into recipes, on a computer you control.

  1. Install Ollama

    Download it from ollama.com ↗ on the same computer as this app’s Python server.

  2. Bring a model home

    Run this in a terminal. The download needs internet once.

    ollama pull qwen2.5:1.5b
  3. Keep Ollama running

    Open the Ollama app, or run ollama serve. Then check the connection below.

No account. No cloud AI. No tracking.
Recipes stay in your browser’s local storage. Notes go to the app server and its configured Ollama host. Use both locally for an entirely on-device workflow. AI can make mistakes; review every recipe and ingredient.
